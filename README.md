# NumpadMouse

Управление мышью с клавиатуры. Один `numpadmouse.exe`, чистый Win32 API,
статический CRT: ни .NET, ни VC++ runtime, ни внешних DLL — только
`kernel32/user32/gdi32/advapi32/shell32`. Работает от Windows 7 и новее.

## Клавиши

| Хоткей | Действие |
| --- | --- |
| **Win+Alt+K** | включить / выключить режим мыши |
| **Win+Alt+Q** | выход |

В режиме:

| Клавиша | Действие |
| --- | --- |
| ↑ ↓ ← → | курсор вверх / вниз / влево / вправо |
| 8 2 4 6 (нумпад) | то же самое |
| 7 | левая кнопка мыши |
| 9 | правая кнопка мыши |
| 5 | средняя кнопка |
| 0 / . | колесо вниз / вверх |
| 1 / 3 | диагонали вниз-влево / вниз-вправо |

- Работает при любом состоянии NumLock (нумпад при выключенном NumLock
  приходит как Ins/Del/Home/End/PgUp/PgDn — это учтено).
- В режиме клавиши съедаются: цифры не печатаются, каретка не двигается.
- Скорость растёт от 2 до 27 px за тик (12 мс) при удержании.
- Включение/выключение подтверждается звуком и иконкой в трее
  (иконка зелёная = режим включён; клик по иконке переключает, правый клик — меню).

## Установка

Просто запустить `numpadmouse.exe`:

1. копия кладётся в `%APPDATA%\NumpadMouse\NumpadMouse.exe`;
2. настраивается автозапуск при входе в систему;
3. процесс остаётся работать в фоне (без окна).

Если запустить **от имени администратора**, автозапуск переводится на задачу
планировщика с повышенными правами (`RunLevel=HighestAvailable`). Это нужный
вариант, если режим должен работать и поверх окон, запущенных от админа
(диспетчер задач, установщики и т.п.) — иначе WinAPI-хук их не видит.

Флаги:

| Аргумент | Действие |
| --- | --- |
| `--install` | установить (копия + автозапуск) и выйти |
| `--uninstall` | убрать автозапуск, задачу и файлы |
| `--noinstall` | запустить без установки и без записи автозапуска |

Удаление: `%APPDATA%\NumpadMouse\NumpadMouse.exe --uninstall`
(если копия запущена — сначала «Выход» в меню трея или Win+Alt+Q).

## Сборка

```
build.bat
```

Нужен MSVC (Visual Studio / Build Tools с компонентом «C++»); `build.bat`
сам находит `vcvars64.bat`. Собирается с `/MT`, поэтому в exe нет зависимости
от распространяемого пакета VC++.

## Ограничения

- UAC-запрос и экран блокировки (secure desktop) — вне досягаемости любого
  низкоуровневого хука; после них состояние клавиш сбрасывается автоматически.
- Без прав администратора ввод не доставляется в окна приложений, запущенных
  с повышенными правами (ограничение UIPI, а не программы).
- Не задумано обходить античиты и защищённые процессы.

## Тесты

```
test\inject.exe          # движение, колесо, автоповтор (клавиши глотаются режимом)
test\inject.exe clicks   # плюс проверка кнопок мыши (реально кликает по курсору)
test\hdr.exe             # показать HDR-состояние мониторов (off|on — переключить)
```

## Отладка

Переменная окружения `NUMPADMOUSE_DEBUG=1` включает лог
`%TEMP%\numpadmouse.log` (события клавиш, переключения, тики движения).
